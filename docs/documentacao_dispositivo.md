# 6. Como o dispositivo foi documentado

Padrões e formatos usados para documentar o dispositivo e os artefatos gerados.

## Convenções adotadas

- Idioma: Português.
- Formato principal: Markdown (`docs/*.md`).
- Exemplos de código mantidos no repositório com docstrings e comentários.

## Artefatos gerados

- `README.md`: visão geral do repositório.
- `docs/*`: documentação organizada por tópicos (este conjunto).
- `podio/repertorio/`: partituras de exemplo em JSON.

## Boas práticas de documentação

- Documentar o formato das mensagens MQTT (campos, tipos).
- Incluir BOMs e diagramas elétricos em `docs/diagrams/`.
- Registrar decisões arquiteturais e trade‑offs em `docs/projeto.md`.
